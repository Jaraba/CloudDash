# Oil & Gas Production Dashboard  
✅ **Tech**: Streamlit, Python
✅ **Features**:  
- Interactive production trends by state using IEA information of crude oil production by state https://www.eia.gov/dnav/pet/pet_crd_crpdn_adc_mbbl_m.htm 
- Deployed on Streamlit Cloud
